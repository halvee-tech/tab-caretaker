# Tab Caretaker Privacy Policy

Last updated: October 26, 2026

Tab Caretaker is a Chrome extension for managing open browser tabs. This policy explains what information the extension accesses, how it is used, and how it is stored.

## Information accessed

To provide duplicate detection, tab grouping, search, local archiving, restoration, and the optional side panel, Tab Caretaker accesses metadata for tabs that are currently open in Chrome. This metadata may include:

- Page URL and title
- Favicon URL
- Tab and window identifiers
- Pinned, active, audible, and group status
- Last-accessed and locally recorded tab-activity times

Tab Caretaker does not read page body content, form entries, passwords, personal communications, keystrokes, mouse movements, or scrolling activity.

## How information is used

The extension uses tab metadata only to provide its disclosed tab-management features:

- Detect and prevent unintended duplicate tabs
- Find and clean up existing duplicate tabs
- Organize tabs into groups by domain
- Display and search open tabs
- Protect selected tabs from automated actions
- Archive inactive tabs locally and restore them later
- Provide operation history and undo support

## Local storage and retention

Settings, tab metadata, archive records, and action history are stored only on the user's device using Chrome's local extension storage. Tab Caretaker has no backend service and does not transmit this information to the developer or any third party.

Locally stored information remains until it is replaced or removed by the extension's retention limits, cleared through Chrome, or deleted when the extension is uninstalled. Users can also restore locally archived tabs from the extension interface.

## Sharing and sale of information

Tab Caretaker does not sell, rent, share, or transfer user data to third parties. It does not use user data for advertising, analytics, creditworthiness, lending, or any purpose unrelated to tab management.

## Remote code and external services

The extension does not download or execute remote code. It does not use external analytics, advertising services, or tracking services. All executable code is included in the extension package.

## Chrome Web Store Limited Use

The use of information received from Chrome APIs adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements. Access is limited to the minimum information needed to provide the extension's disclosed single purpose.

## Changes to this policy

If Tab Caretaker's data practices change, this policy and the Chrome Web Store disclosure will be updated before the changed practices are introduced.

## Contact

For privacy questions or requests, open an issue in the [Tab Caretaker GitHub repository](https://github.com/halvee-tech/tab-caretaker/issues).

# Tab Caretaker 隐私权政策

最后更新：2026 年 10 月 26 日

Tab Caretaker 是一款用于管理浏览器已打开标签页的 Chrome 扩展。本政策说明扩展会访问哪些信息、如何使用这些信息以及如何保存这些信息。

## 访问的信息

为了提供重复标签识别、标签分组、搜索、本地归档、恢复以及可选的标签侧边栏功能，Tab Caretaker 会访问 Chrome 当前已打开标签页的元数据，包括：

- 页面网址和标题
- 网站图标网址
- 标签页和窗口标识符
- 固定、激活、声音播放及分组状态
- 最后访问时间及扩展在本地记录的标签活动时间

Tab Caretaker 不读取网页正文、表单内容、密码、个人通信内容、键盘输入、鼠标移动或滚动行为。

## 信息用途

扩展仅将标签页元数据用于已披露的标签管理功能：

- 识别并阻止非预期的重复标签页
- 查找和清理已有重复标签页
- 按域名整理标签组
- 展示和搜索已打开标签页
- 保护指定标签页，避免自动处理
- 在本地归档长期未使用的标签页并支持恢复
- 提供操作历史和撤销功能

## 本地存储与保留

设置、标签页元数据、归档记录和操作历史仅通过 Chrome 的扩展本地存储保存在用户设备上。Tab Caretaker 没有后端服务，也不会将这些信息传输给开发者或任何第三方。

本地信息会一直保留，直至被扩展的保留上限替换或移除、用户通过 Chrome 清除扩展数据，或者用户卸载扩展。用户也可以通过扩展界面恢复本地归档的标签页。

## 信息共享与出售

Tab Caretaker 不会向第三方出售、出租、共享或传输用户数据，也不会将用户数据用于广告、分析、信用评估、贷款或任何与标签管理无关的用途。

## 远程代码与外部服务

扩展不会下载或执行远程代码，也不使用外部分析、广告或跟踪服务。所有可执行代码均包含在扩展安装包内。

## Chrome 应用商店有限使用要求

Tab Caretaker 对 Chrome API 所提供信息的使用遵守 Chrome 应用商店用户数据政策，包括有限使用要求。扩展仅访问实现其已披露单一用途所必需的最少信息。

## 政策变更

如果 Tab Caretaker 的数据处理方式发生变化，我们会在实施变更之前更新本政策和 Chrome 应用商店中的相关声明。

## 联系方式

如有隐私相关问题或请求，请在 [Tab Caretaker GitHub 仓库](https://github.com/halvee-tech/tab-caretaker/issues)中提交 Issue。
